# D-F 代理模型 LOO 验证报告 (ConstDF-v1)

## 方法

每个 TPMS 类型独立训练一个 3 输入 × 2 输出的 MLP ensemble(5×):

```
输入: (log10 L, log10 t, log10 ε_f) → z-score 归一化
MLP:  Linear(3, 32) → SiLU → Dropout(0.05)
      Linear(32, 32) → SiLU → Dropout(0.05)
      Linear(32, 2)
输出: (log10 K, log10 c_F) ← 反归一化到物理空间

ΔP_pred,i = ( μ_i u_i / K(L, t, ε_f)
            + ρ_i c_F(L, t, ε_f) · u_i² ) · L_ch

L_ch = K_S_CELLS · L_cell_m,    K_S_CELLS = 10
损失 = mean ( (ΔP_pred - ΔP_obs) / ΔP_obs )²
优化 = Adam(lr=1e-3, wd=3e-4) + ReduceLROnPlateau + 早停
```

K 和 c_F 是几何级常数(无 Re 依赖)。Re 独立性前置证据见 
`reports/constdf-v1/2026-04-14-DF-re-independence-report.md` —— 24/24 几何
通过 Pearson 残差-Re 检验,物理上 2 参数 D-F 闭合在当前训练集
Re 范围内是合法的。

## 注

- `K_ref (2p)` / `c_F_ref (2p)` 来自 Step 2 的每几何 2 参数 WLS,作为
  参考,代理模型目标是在 LOO 下尽量接近这些常数。
- `K_pred` / `c_F_pred` 是 LOO 留出几何的 ensemble 平均预测,代入该几何
  所有 CFD 行做 per-row ΔP 残差。
- **ΔP MAPE 是主指标**,汇总到 TPMS 级给出论文可引用的代理精度。
