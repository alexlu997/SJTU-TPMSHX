# D-F 代理模型 LOO 验证报告 v2 (Re-dependent K_eff, c_F_eff)

## 方法

每个 TPMS 类型独立训练一个 4 输入 × 2 输出的 MLP ensemble(5×):

```
输入: (log10 L, log10 t, log10 ε_f, log10 Re) → z-score 归一化
MLP:  Linear(4, 32) → SiLU → Dropout(0.05)
      Linear(32, 32) → SiLU → Dropout(0.05)
      Linear(32, 2)
输出: (log10 K_eff, log10 c_F_eff) ← 反归一化到物理空间

ΔP_pred,i = ( μ_i u_i / K_eff(L, t, ε_f, Re_i)
            + ρ_i c_F_eff(L, t, ε_f, Re_i) · u_i² ) · L_ch

L_ch = K_S_CELLS · L_cell_m,    K_S_CELLS = 10
损失 = mean ( (ΔP_pred - ΔP_obs) / ΔP_obs )²
优化 = Adam(lr=1e-3, wd=3e-4) + ReduceLROnPlateau + 早停
```

**关键变化(相对 v1)**:MLP 输入维度 3 → 4(新增 log10 Re),输出 K 和 
c_F 不再是几何常数,而是 Re 的**连续函数**。这样驼峰形残差(Re ≈ 1500 附近 
系统偏差)可以被 c_F_eff(Re) 的非单调变化吸收。文献支持:Barree-Conway 
2004、arxiv 2510.10622 (2026)。

## 注

- `K_ref (2p)` / `c_F_ref (2p)` 来自 Step 2 的每几何 2 参数 WLS,**常数** ——
  仅作为 legacy 参考,不是 v2 模型的 ground truth。新模型里 K 和 c_F 都是 Re 
  的连续函数,无单值参考。
- `K_pred (mean Re)` / `c_F_pred (mean Re)` 是留出几何所有行的 K_eff 和 c_F_eff 
  的**几何平均**,等于 log 空间的算术平均。只是为了让人眼能看出和 2 参数参考
  的量级关系。
- **ΔP MAPE 才是主指标**,在每行上用该行的 Re 做了忠实的 per-row 预测。
