TPMS 换热器逆向定尺 — 计算流程规格 (模型无关 / AI 通用)

目的: 给定多工况边界条件 + 均质化闭合, 确定性地反推 TPMS 换热器最优尺寸。
无 BO / 无 ML 优化器 — 纯方程 + 单调二分 + 枚举择优, 任何 AI 或引擎可复现。
主计算路径 = 项目均质化 3D LTNE PDE (§2 路径 B) — 三温耦合含固体+燃油侧
串联热阻, 为本项目权威前向, 全部定尺/回填均走此路。解析 LMTD/切片
(路径 A/A', wall≡fuel 乐观) 仅作便携交叉校核 / 无 PDE 环境快算, 不作定尺依据。

0. 输入 / 输出

输入 (每工况 k, 共 N 个):

  • P_in 空气进口绝对压力 [Pa]
  • T_air_in 空气进口温度 [K]
  • m_air 空气质量流量 [kg/s]
  • m_fuel 燃油质量流量 [kg/s]
  • T_f_in 燃油进口温度 [K]
  • (设计目标) T_air_out_spec 空气出口上限 [K]; dP_spec 压损上限 [-]

输出: 最优 (拓扑, 晶胞 l, 壁厚 t, 迎风 W=H, 流程 Lx); 每工况 (T_air_out, T_f_out, dP); 重量。

几何约定: 空气沿 x (长 Lx); 迎风面 = y·z = W×H (方形 W=H=s); 燃油 cross-flow (⊥)。

1. 物性与闭合 (可替换块)

1.1 空气物性 (T[K], P[Pa])

ρ  = P / (R_air · T),         R_air = 287.05
cp = 1004.5 + 0.172·θ − 7.56e-5·θ²,   θ = T − 273.15        [J/kg·K]
μ  = 1.716e-5 · (T/273.15)^1.5 · (273.15+110.4)/(T+110.4)   [Pa·s] (Sutherland)
k  = 0.0241 · (T/273.15)^0.82                               [W/m·K]
Pr = 0.72  (常数)

1.2 燃油 Cp (航空煤油 Jet A, T[K])

Cp_fuel = (0.787 + 0.004·T) · 1000      [J/kg·K]   (≈2.3–2.4 kJ/kgK @ 400K)

1.3 几何均质化 (拓扑, l[mm], t[mm]) — 项目特定, 换几何须替换

ε     = ε(拓扑, l, t)          全孔隙率 (TPMS 标定表 / 或 CAD 相对密度 1−ρ_rel)
ε_A   = ε / 2                  单股孔隙率 (sheet HX 两股均分)
A_0   = A_0(拓扑, l, t)        单侧比表面密度 [1/m]
D_h   = 4·ε_A / A_0            水力直径 [m]

1.4 换热闭合 Nu (单股, Pr=0.72; f_rough 粗糙因子用户选)

Diamond: Nu = f_rough · 0.0944 · Pr^(1/3) · Re^0.8273 · (D_h/l)^0.226
Gyroid : Nu = f_rough · 0.126  · Pr^(1/3) · Re^0.7898 · (D_h/l)^0.2409
         f_rough ∈ {1.0, 1.14, 1.28}  (换热侧 Nu 标度因子, 用户选)
h = Nu · k / D_h               [W/m²·K]
有效域: Re ∈ [400, 16000]      (超出 = 外推, 标记)
⚠ f_rough 只乘换热侧 Nu, 绝不乘 dP (§1.5)。早期把 1.28 叙述为"SLM 粗糙/
2D-artifact 补偿"是已修正的旧叙事 — Nu 关联式系数已含其标定数据特性;
f_rough 是额外换热标度, 用户按工况选, 须与所用标定一致并显式声明。

1.5 压降闭合 Darcy-Forchheimer (可压缩等温) — K,c_F 项目特定

K, c_F = K_cF(拓扑, l, t, ε_A)   渗透率[m²]/惯性系数[1/m] (代理模型/或拟合)
G  = m_air / (ε_A · W·H)          间隙质量流密度 [kg/m²s]
P_out² = P_in² − 2·R_air·T_m·(μ·G/K + c_F·G²)·Lx
dP = P_in − √P_out² ;  dP_frac = dP/P_in
注: 此式 = 微分式 −dP/dx = μu/K + ρ·c_F·u² 在等温积分; 用均温 T_m 与逐点
非等温 march 差 <0.1% (Forchheimer ∝T 线性 + T 近线性)。
⚠⚠ **K/c_F 标定自 SLM 试件实测压降 → 表面粗糙已含在内。dP 侧绝不可再乘
f_rough (§1.4), 否则粗糙度被 double-count** (项目定论, 见 dP-gap 归因)。
f_rough 仅作用换热 Nu (§1.4), 与 dP 闭合互不交叉。

2. 前向模型 (给定 几何 + 单工况 → T_air_out, Q, dP)

主路径 = 路径 B (均质化 3D LTNE), 项目权威前向, 所有定尺/回填用此。
A/A' 仅便携交叉校核 (wall≡fuel 乐观, 偏小 ~40% 体积), 非定尺依据。

路径 B — 3D LTNE 均质化 PDE ★主计算路径

解 (Ta 空气, Ts 固体, Tb 燃油) 三温耦合场:

空气:  ρ·cp·u·∂Ta/∂x = h_vA·(Ts − Ta)
固体:  ∇·(k_s·∇Ts) + h_vA·(Ta − Ts) + h_vB·(Tb − Ts) = 0
燃油:  Tb = prescribed (均匀 = 燃油均温, 或线性; 冻结)
h_vA = A_0·h_air ;  h_vB = A_0·h_fuel (煤油 Reynolds 类比, 含燃油侧热阻)
T_air_out = 出口面质量流加权均温 ;  dP ← §1.5

固体是独立温度节点 → 空气经 h_vA → 固体 → h_vB → 燃油 串联热阻;
固体实温 > 燃油 (被空气加热) → 有效壁温更高 → 比 wall≡fuel 多 ~40% 体积
(诚实保守值)。外层燃油耦合 (壁温=燃油均温, 1 种子+2 迭代) 见 §3b。
求解器 solve_full_domain_3d (镜像 validate_shanghai_3d_real)。

附: 简化交叉校核 (非主路径; wall≡fuel 乐观, 不作定尺依据)

路径 A — 解析 LMTD/UA-direct (最便携, 无 PDE, 逆解尺寸)

T_m   = (T_air_in + T_air_out_target)/2        # T_out 目标已知 → 无迭代
ρ,μ,k,cp ← 1.1 @ T_m
u     = m_air / (ρ · ε_A · W·H)                # 间隙速度
Re    = ρ·u·D_h/μ ;  Nu ← §1.4 关联式 ;  h = Nu·k/D_h
# LMTD (逆流; 燃油近等温 C_r≈0 → cross-flow 修正 F≈1):
ΔT1   = T_air_in − T_f_out ;  ΔT2 = T_air_out_target − T_f_in
LMTD  = (ΔT1−ΔT2)/ln(ΔT1/ΔT2)
Q     = m_air·cp·(T_air_in − T_air_out_target)
A_req = Q / (h·LMTD)                           # 需要换热面积 [m²]
Lx    = A_req / (A_0 · W·H)                     # ← A=A_0·V 直接解, 无 Lx 迭代
dP    ← 1.5
用于定尺正问题 (给定 T_out 目标反解 Lx)。前向校核时 (给定几何算 T_out) 见路径 A'。

路径 A' — 前向 (给定几何 + 燃油耦合迭代, 用于回填工况表)

T_wall = T_f_in                                # 初猜 (燃油近等温, 猜值不敏感)
repeat 2 次:
    # 单股定壁温: 沿 Lx 分 n 切片, 每片精确解
    T_air = T_air_in
    for 每切片 (dx=Lx/n):
        props @ T_air ;  u=m_air/(ρ·ε_A·W·H) ; Re ; Nu(×f_rough) ; h
        NTU_s = h·(A_0·W·H·dx)/(m_air·cp)
        T_air = T_wall + (T_air − T_wall)·exp(−NTU_s)      # 定壁温解析
    T_air_out = T_air
    Q = m_air·cp̄·(T_air_in − T_air_out)
    T_f_out = T_f_in + Q/(m_fuel·Cp_fuel(T_f_mean))         # Cp ← 1.2
    T_wall  = (T_f_in + T_f_out)/2                          # 燃油均温给壁
dP ← 1.5

3. 单胞元定尺 (确定性, 无 BO)

两种 mode, 按目标选 (本规格两者都用过, 对应两条工作线):
- §3a 自由设计 (求最小尺寸/重量): 迎风 s 可变 → dP 主动。
→ 产出本项目"最优件" Diamond l6 t0.4 (dp2530/select/compromise 系列)。
- §3b 固定包络 (envelope 由规格卡给死, 如 84×84): 仅 Lx 自由 → T 主动, dP 松弛。
→ 产出 D-7-5 / D-6-4 工况回填 (84×84×28 等固定箱)。

§3a 自由设计 (变迎风, dP-active)

目标: 最小体积满足 (空气出口 ≤ T_target) 且 (dP ≤ dP_limit), 全 N 工况。

关键单调性:

  • V = W·H·Lx = Q/(h·LMTD·A_0) ∝ 1/h ; h ↑ 当 s↓ (Re↑) → V↓ 当 s↓
  • dP ∝ u² ∝ 1/s⁴ → dP↑ 当 s↓
  • ⟹ 最小体积落在 dP = dP_limit (限值 active)

算法 (联合多工况):

对迎风边 s 二分 (单调: dP_max 随 s↓ 升):
    Lx(s) = max over 冷却-governing 工况 of [ 路径 B 3D 解 Lx 至 T_target ]  # 主路径
            (便携校核: 路径 A 解析 Lx = A_req,k/(A_0·s²))
    dP_max = max over 全 N 工况 of dP_frac(s, Lx(s))                 # 1.5
    收敛到 dP_max = dP_limit
→ (s*, Lx*) = 该胞元最小体积件
冷却-governing = 最高 T_air_in 工况池 {取 Lx 最大者}
dP-governing  = 最高质量流密度 G 工况 (最高 m_air/面积)

§3b 固定包络 (迎风 s 固定, 扫 Lx, T-active)

适用: envelope 由外部规格卡给死 (如芯体 84×84×28mm, 迎风 W=H 固定)。仅流程
Lx 自由; dP 非主动 (大迎风 → 低速 → dP 远低于限, 松弛)。

迎风 W=H = 规格给定 (固定)
对 Lx 二分 (单调: 空气出口 T 随 Lx↑ 降):
    各工况前向 (§2 路径 B 均质化) → T_air_out,k
    收敛到 governing 工况 T_air_out = T_target
    (governing = 最难冷却工况 = 最高 T_air_in / 最高 ṁ_air·cp;
     取使 Lx 最大的工况, 保所有工况都 ≤ T_target)
→ Lx*; 校核全工况 dP (§1.5) ≤ dP_spec (通常大裕度); 重量 ← §5
若规格连 Lx 也给死 (如 28mm): 退化为**纯前向校核** (无二分),
直接算每工况 T_out/dP/T_f_out (= D-7-5/D-6-4 工况回填所做)。
§3a vs §3b 选择由"envelope 是否硬约束"决定: 自由 → §3a 求最小; 给死 → §3b。
单调性 (T↓ 随 Lx↑; dP↑ 随 Lx↑ 且 ∝1/s⁴ 随 s↓) 两 mode 共用, 仅 active 约束不同。

4. 多目标选型 (枚举择优, 仅 §3a 自由设计适用)

候选 = 拓扑{Diamond,Gyroid} × l{验证节点} × t{验证节点}    # 留插值域内
对每候选: 跑 §3 定尺 → (s,Lx,V) ; 全 N 工况前向校核 (§2) →
          T_out_max, dP_max, Re_max ; 重量 ← §5
可行 = (T_out_max ≤ T_spec) 且 (dP_max ≤ dP_spec) 全工况
排序目标: min V / min 重量 / min dP / max 流向晶胞(Lx/l, 均质化稳)
标记: Re_max>16000 (Nu 外推); l/t 在节点边界 vs 内点 (插值置信)

5. 重量

重量 = (1−ε)·V·ρ_s = N_cells · (1−ε)·l³ · ρ_s    (恒等; N_cells=V/l³)
ρ_s = 7900 kg/m³ (304 SS; 换牌号按比例)

6. 鲁棒性派生 (可选, 建余量)

T_target  ← T_spec − ΔT_margin   (如 603→580, 留 23K 冷却余量)
dP_limit  ← dP_spec − Δp_margin  (如 5%→2.9%, 留 ~2pp dP 余量)
偏好: l,t 取节点内点 (非边界/缺口) → 插值最稳

余量吸收闭合不确定 (本项目 LOO ±~12%); 代价 = 体积/重量↑。

7. 有效域 / Caveats (定级须声明)

1. 几何插值域: l,t 须在闭合训练节点凸包内 (本项目 l∈{4,5,6,8} 节点, 7=缺口;
t∈{0.3,0.4,0.5}); 出域 = 外推, 低置信。
2. Re 窗: Nu 有效 Re∈[400,16000]; 大孔→高 Re 易外推。均质化-晶胞数 vs Re-窗互斥:
大孔↑流向晶胞(均质化稳)但↑Re(Nu 外推)。
3. 闭合标定域: Nu/D-F 标定于具体工质+工况 (本项目 Shanghai 空气-水近常温);
迁移到新工质/高温 = 端到端无独立验证 → "模型设计估计 + 不确定带"。
4. 燃油侧简化: prescribed 壁温 (C_r≈0 近等温成立); wall≡fuel 无燃油侧热阻=乐观,
含阻 (路径 B h_vB 有限) 更真实 (+~40% V)。
5. 均质化有效性: 流向晶胞 Lx/l 越多越稳 (理想 ≥~8–10); 固定 dP+duty 物理上限 ~4–6。
6. f_rough 换热标度: 用户选 (1.0/1.14/1.28); 只乘换热 Nu (§1.4), 绝不乘 dP (§1.5)
— dP 闭合已含实测粗糙, 再乘 = double-count (项目定论)。须与标定一致且显式声明。
7. air-air 工况无独立 CFD 验证: 后端支持 air-air 流体分派, 但项目验证靶 = air-water
Shanghai 叉流; air-air 结果 = 方法自洽 + 闭合外推 (部分低 Re), 非端到端实验/CFD 背书。
相对比较/初筛可信; 绝对值需后续 CFD/实验确认。

8. 适配到其他换热器 (替换清单)

换不同 TPMS / 工质时, 替换:

  • §1.3 几何映射 ε/A_0/D_h ← 新拓扑标定表或 CAD
  • §1.4 Nu 关联式系数 + 有效 Re 域 ← 新拟合
  • §1.5 K/c_F 渗透率模型 ← 新拟合
  • §1.1/1.2 工质物性 ← 新流体
  • §3 单调性 (V↓dP↑ 随 s↓) 拓扑无关, 算法不变
  • §0/§2 流动布置 (cross/counter) — 若一股非近等温 C_r 不≈0, 须真共轭双股 (弃 prescribed)

算法骨架 (§2–§6) 与具体闭合解耦 — 这是"AI 通用"的部分。

9. 快速设计接口 (单模块, 实现于 sjtu_tpmshx/design/)

输入 Excel (多行工况 × 列): 两侧 {流体∈air/water, T_in[K], P_in[kPa], ṁ[kg/s]} + Q_kW 或 dT_h_K (二选一: 热侧换热量或温降) + 两侧 ΔP 上限 (分数)。

模式:

  • fixed = baseline: 固定 (拓扑, l, t), 只定外形 (s, Lx)。
  • auto = 优化: 枚举 {拓扑 × l × t} 节点, 各定外形, 取 Pareto (min-V / min-重量 / min-dP)。
  • --refine: 对 auto 最优件做连续 (l, t) warm-start 精修 (Nelder-Mead, 训练凸包内); 不优于节点最优则回退。

前向 = LTNE (§2 path B, 双流股都解, plug 速度)。叉流 A 沿 +x / B 沿 +y, 塌 Nz=1 走 2D 内核 (垂直流股, 稳定快, 能量 gap ~1.5%)。逆流 B 沿 −x: 两股同轴反向在无欠松弛的 2D 内核会极限环 (水出口在两态跳, gap 7-33% 不收敛) → 改用 Nz=2 路由到支持 α 的 3D 内核 + 低 α(0.3) 欠松弛 → 稳定 gap ~0.4%。(注: 2D 内核 solve_full_domain 本身未加欠松弛/未修 = YAGNI; 谁直接调 2D 内核跑同轴逆流仍会极限环。)

dP 按流体分派 (§1.5 闭合, 同一 K/c_F 几何渗透率, 仅密度处理不同):

  • air (可压) → 理想气体积分 $P_{\text{out}}^2 = P_{\text{in}}^2 - 2RT\left(\tfrac{\mu G}{K}+c_F G^2\right)L$。
  • water (不可压) → $\Delta P = \left(\tfrac{\mu u}{K}+\rho\,c_F\,u^2\right)L$ (常数 ρ)。勿对水用可压式 — 其内嵌 ρ=P/(R_air·T) 会把水密度算成 ~2 而非 ~988, dP 偏大 ~450× → 恒不可行。

迎风面积 (开口流通 = ε_A × 毛迎风, 决定质量通量 G 与孔隙速度 u, 进而 dP):

流股流向迎风面毛面积流程
空气±xy–zs²Lx
水 (叉流)+yx–zLx·ss
水 (逆流)−xy–zs²Lx
⚠ 叉流冷侧迎风 = Lx·s (含 Lx): 薄板 Lx≪s → 水进口是窄缝 → 高流速高 dP, 是真实物理, 非 artifact。

定尺算法 (取代纯 s 二分): min-V over s — 扫 s, 每个 s 内定
Lx = max(Lx_冷却, Lx_使两侧dP达标), 受 450mm 与热侧 dP 上限约束 (热侧 dP 随 Lx↑), 取 V=s²·Lx 最小者。叉流冷侧 dP 随 Lx↓ (迎风 Lx·s 变大) → 给 Lx 下界; 逆流冷侧迎风 s² 与 Lx 无关 → 退化回 Lx=Lx_冷却。冷却仅对 governing 工况 (0-D 预选) 跑 2D, 其余工况 dP 纯解析; s* 处全 K 冷却终验。

硬约束 s, Lx ≤ 450mm (build envelope)。输出 (拓扑, l, t, W×H×Lx, V, 重量, 两侧 dP, T_out_max)。

命令: python -m design.cli --xlsx spec.xlsx --mode auto --refine --out 设计结果.xlsx
